# Tutorsite
В этом файле будет написанны описания для элементов и примерная планировка всего сайта.

## Приложения и для чего нужны (примерное описание функционала)
| № | Название Приложения (App) | Основной Функционал | Ключевые Модели (Примеры) |
| :---: | :---: | --- | --- |
| 1	| `users` | Управление пользователями, аутентификацией и профилями. |	`CustomUser`, `Profile` (флаг: `is_tutor`/`is_student`) |
| 2	| `tutors` | Каталог репетиторов, их информация и поиск. |	`TutorProfile`, `Subject`, `TutorAvailability` (расписание) |
| 3	| `reviews` |	Система отзывов и рейтингов. |	`Review`, `Rating` |
| 4	| `lessons` |	Управление бронированием и расписанием уроков. |	`Booking`, `Lesson` (запланированный/проведенный урок) |
| 5	| `payments` |	Обработка транзакций, счетов и интеграция с платежными системами. |	`Transaction`, `Invoice`, `Wallet` (баланс пользователя/репетитора) |
| 6	| `chat` |	Обеспечение связи между учеником и репетитором (сообщения, чат). |	`Conversation`, `Message` |
| 7	| `core` |	Содержит общие настройки, шаблоны и базовые классы, используемые во всем проекте (например, базовые модели с created_at). |	(Не имеет собственных моделей, только базовые клаги и утилиты) |
